# Brief para imágenes de productos Joyan

**Corte: 2026-11-05.** Encargo reutilizable para un agente generador de imágenes. La dirección parte del hero de la landing; su adaptación a cada producto es una propuesta para revisar, no una identidad de producto ya aprobada. Fuente de contexto: [identidad visual actual](IDENTIDAD-VISUAL-ACTUAL.md).

## Antes de generar

Completá con información confirmada; si falta, pedila o marcá el resultado como conceptual:

- **Producto o agente:** [nombre autorizado o descripción genérica].
- **Qué hace realmente y para quién:** [una frase basada en información verificable].
- **Concepto visual concreto:** [qué objeto, relación o escena representa esa función, sin inventar capacidades].
- **Uso y formato:** [portada, imagen editorial, miniatura u otro; proporción y resolución].
- **Referencias visuales disponibles:** [captura o enlace de la maqueta aprobada; assets oficiales y permisos].
- **Marca y texto:** [sin texto / espacio para composición posterior / asset oficial aportado].
- **Restricciones particulares:** [contenido prohibido, accesibilidad o requerimientos de publicación].

## Dirección visual

Representar un producto de Joyan dentro de un **espacio oscuro con profundidad**, evocando una constelación o nebulosa sin copiar literalmente la composición del hero. El sujeto del producto debe poder distinguirse: el entorno no reemplaza la idea.

- Fondo de referencia casi negro `#020405`; luz clara desaturada `#B4CABE` y matices fríos de petróleo a celadón. Son anclas cromáticas, no una promesa de coincidencia exacta del generador.
- Construir profundidad con cielo de puntos, atmósfera tenue, figura o sistema de nodos, viñeta suave y núcleos de luz. Mantener planos posteriores visibles.
- Usar **puntos discretos, dithering y densidad variable** para sugerir volumen y transiciones. Oscuridad dominante, luz concentrada, jerarquía clara y espacio negativo.
- Evitar ruido homogéneo, glow excesivo, gradientes SaaS, glassmorphism, paleta papel como si estuviera aprobada, acentos nuevos no acordados, texto ilegible, logotipos inventados e interfaces que prometan funciones no confirmadas.
- No producir texto o marca final dentro del generador salvo que el encargo lo pida expresamente: dejar espacio y añadir los assets oficiales en una etapa posterior.

## Prompt base para adaptar

> Crear una imagen conceptual para **[producto o agente]**, que ayuda a **[función real y usuario]**. Representar **[metáfora visual concreta]** como sujeto principal, en un entorno de espacio profundo inspirado en el lenguaje visual oscuro de Joyan: fondo casi negro `#020405`, luz desaturada cercana a `#B4CABE`, matices fríos petróleo y celadón, y capas distinguibles de cielo de puntos, atmósfera sutil y conexiones o nodos cuando tengan sentido para el sujeto. Construir forma, luz y profundidad mediante puntos discretos, dithering y variación de densidad y tamaño; conservar mucho espacio oscuro y puntos de luz contenidos. Composición **[encuadre]**, formato **[relación de aspecto y resolución]**, con **[espacio reservado para marca o texto, si corresponde]**. Sin texto generado, logotipos inventados, estrellas uniformes, glow excesivo, glassmorphism, degradado SaaS genérico ni funcionalidades no verificadas.

## Ejemplo conceptual, no descripción de producto real

> Imagen editorial horizontal 16:9 de un **agente hipotético que ayuda a revisar documentos**: una forma abstracta de documento compuesta por puntos, conectada a un pequeño conjunto de nodos, con un punto de decisión humano sugerido sin mostrar una interfaz ni inventar estados. Fondo casi negro, atmósfera de nebulosa tenue y capas de puntos en petróleo y celadón desaturado; iluminación contenida, espacio negativo y dither visible. Sin texto, logo, capturas de app ni símbolos de certificación.

## Revisión de cada propuesta

1. ¿El sujeto y la función visual se entienden sin inventar hechos sobre el producto?
2. ¿Se lee como el universo oscuro y por capas de Joyan, en vez de una galaxia genérica o ruido uniforme?
3. ¿El dither y la luz aportan forma sin tapar el sujeto ni hacer ilegible una futura composición?
4. ¿El formato deja espacio para el uso previsto y para marca/texto reales cuando correspondan?
5. ¿La persona responsable aprobó la pieza? Una generación coherente con este brief sigue siendo una propuesta.
