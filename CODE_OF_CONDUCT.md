# Code of Conduct

## Our Standards

Contributors are expected to be respectful, constructive, and inclusive. Welcome questions, explain technical disagreement with evidence, and focus feedback on the work rather than on people.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, sharing private information, and publishing sensitive security information.

## Enforcement

Maintainers may remove comments, close discussions, or restrict participation when behavior violates these standards. Report conduct concerns privately through a GitHub channel to a repository maintainer. Do not include private or sensitive information in a public issue.

This project does not publish a maintainer email address; use GitHub's private communication features instead.
