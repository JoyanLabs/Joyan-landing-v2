# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through the repository's GitHub Security tab and private vulnerability reporting feature when available.

If private vulnerability reporting is not enabled, request a private GitHub communication channel from a maintainer. Do not open a public issue or pull request containing credentials, tokens, private keys, certificates, exploit details, or other sensitive material.

Include enough information for maintainers to reproduce and assess the issue, while sharing the minimum sensitive detail necessary. Please wait for maintainer guidance before disclosing the issue publicly.

## Safe Contributions

- Never commit `.env` files, credentials, tokens, private keys, certificates, or local deployment configuration.
- Review generated files and Docker build contexts before submitting a pull request.
- Keep sensitive scan output and private infrastructure details out of issues, pull requests, and documentation.
