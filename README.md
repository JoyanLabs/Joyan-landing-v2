# 🚀 Joyan Landing Template

Plantilla de landing page de alta calidad construida con **Astro 5** + **Tailwind CSS**.

## Características

- ✅ Alta performance y SEO
- ✅ Soporte para React, Vue y Svelte
- ✅ Dark mode integrado
- ✅ Componentes UI reutilizables
- ✅ Agent Skills integrados para desarrollo con IA
- ✅ Configuración de VSCode lista para usar
- ✅ Linting y formateo con Biome + ESLint + Prettier

## Inicio Rápido

```bash
# Clonar el repositorio
git clone https://github.com/JoyanLabs/joyan-landing-template.git

# Instalar dependencias
pnpm install

# Iniciar servidor de desarrollo
pnpm dev
```

## Comandos

| Comando        | Descripción            |
| -------------- | ---------------------- |
| `pnpm dev`     | Servidor de desarrollo |
| `pnpm build`   | Build para producción  |
| `pnpm preview` | Preview del build      |
| `pnpm check`   | Verificar tipos y lint |
| `pnpm lint`    | Biome lint             |
| `pnpm format`  | Formatear código       |
| `pnpm fix`     | Auto-fix               |

## Estructura

```
src/
├── components/    # Componentes
├── layouts/       # Layouts
├── pages/         # Páginas
├── content/       # Contenido
└── config.yaml    # Configuración
```
