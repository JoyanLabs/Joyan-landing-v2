OFL NOTICE — typography comparison harness
==========================================

Every font file in typo/fonts/ was fetched during this study from the Google
Fonts CSS API (https://fonts.googleapis.com/css2?family=...) with a browser-like
User-Agent, which returns woff2 URLs on fonts.gstatic.com. Nothing was taken
from a package manager, and nothing was copied into public/fonts/. Four families
are shipped; the fifth sample on the page (the control) uses the platform's
system sans and ships no file.

Each family is distributed under the SIL Open Font License, Version 1.1. The
full licence text for each was fetched from the upstream google/fonts
repository and is kept beside this notice as OFL-<family>.txt; each fetched file
was checked to begin with that family's own copyright line (quoted below). The
canonical licence description is at https://openfontlicense.org.

Not shipped
-----------

The control sample (candidate E) uses the platform's system sans via the CSS
font stack "system-ui, Helvetica Neue, Helvetica, Arial, sans-serif". No font
file is shipped for it, no licence is claimed for it, and its rendered metrics
depend on the machine that opens the page.

Scope
-----

These files live in design-studies/visual-directions/typo/fonts/ and are study
assets, not landing assets. Nothing in public/fonts/, src/, scripts/ or the
slice pages references them.
